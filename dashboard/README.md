# 🍃 どう森BOT 管理ダッシュボード

`doumori` Discord Bot専用の管理ダッシュボードです。Next.js製で、Bot本体と同じデータベース（`DOUMORI_DATABASE_URL`）に直接接続し、Webブラウザから各種設定を編集できます。保存内容はBotに即時反映されます。

以前は `manybot` 側のダッシュボードに間借りしていた設定画面（浮上特典・ミッション管理・階級設定・マイル手動操作・総合パネル送信）を、この専用サイトに統合したものです。1つのDiscordサーバーのみを管理する、単一テナント構成のツールです。

---

## 📋 前提条件

- Node.js 18以上を推奨
- どう森BOT本体（`../`）が使用しているものと同じ Supabase / PostgreSQL データベース
- Discord Bot Token（どう森BOT本体と共通のものでOK）
- 管理したいDiscordサーバー（Guild）のID

---

## 🚀 セットアップ手順

### 1. 依存パッケージのインストール

```bash
cd dashboard
npm install
```

### 2. 環境変数の設定

`dashboard/.env.local` を新規作成し、以下を設定します（`.env.example` をコピーすると簡単です）。

```bash
cp .env.example .env.local
```

| キー (Key) | 説明 | 例 |
| :--- | :--- | :--- |
| `DOUMORI_DATABASE_URL` | Bot本体と同じDoumori専用DB接続文字列 | `postgresql://postgres.xxxx:password@aws-0-region.pooler.supabase.com:6543/postgres` |
| `DISCORD_BOT_TOKEN` | Bot本体と同じDiscord Bot Token（チャンネル/ロール取得・パネル送信に使用） | `MTIzNDU2Nzg5...` |
| `DASHBOARD_GUILD_ID` | このダッシュボードが管理する対象サーバーのGuild ID（1サーバー専用） | `123456789012345678` |
| `DASHBOARD_USERNAME` | ダッシュボードのログインユーザー名 | `admin` |
| `DASHBOARD_PASSWORD` | ダッシュボードのログインパスワード | 任意の強いパスワード |
| `JWT_SECRET` | セッション署名用のランダムな秘密文字列 | 32文字以上のランダム文字列推奨 |

> `DASHBOARD_GUILD_ID` を省略した場合は、Bot本体の `SYNC_GUILD_ID` 環境変数が利用されます（どちらも未設定だと動作しません）。

### 3. 起動

開発モード:

```bash
npm run dev
```

`http://localhost:3000` にアクセスし、`DASHBOARD_USERNAME` / `DASHBOARD_PASSWORD` でログインします。

本番ビルド・起動:

```bash
npm run build
npm start
```

### 4. デプロイ（例: Render / Vercel など）

- Node.jsが動くホスティングであればどこでもデプロイ可能です（Bot本体をRenderで運用しているなら、同様にRenderのWeb Serviceとしてデプロイするのが簡単です）。
- ビルドコマンド: `npm install && npm run build`
- 起動コマンド: `npm start`
- 上記の環境変数一覧をすべてホスティング先の環境変数に登録してください。

## 🖥️ 画面の使い方

ログイン後、左サイドバーから各設定画面に移動できます。

### 基本設定 (`/dashboard`)

Bot全体の各種パラメータを1画面で編集します。

- **🎫 浮上・チケット獲得**: VC/チャット浮上によるチケット付与条件、達成通知の送信先・文面
- **🏪 ショップ・両替**: `/ショップ` `/両替` の価格・レート
- **🎣 採集**: `/釣り` `/虫捕り` の色違い出現率、図鑑の1ページ表示件数
- **🏆 限定コンプリートロール付与**: 図鑑100%コンプリート時に自動作成・付与されるロール名とカラー
- **🪙 生き物売却**: `/売却` でのレアリティ別ベル換算額
- **📸 ミッション報告**: 1日あたりのデイリーミッション受注枠数、報告先チャンネル

編集後は右上（またはページ下部）の「保存する」を押すとBotに即時反映されます。

### デイリーミッション管理 (`/dashboard/missions`)

- 新規ミッションの作成（タイトル・達成条件・対象階級・報酬マイル）
- 既存ミッションの有効/無効切り替え・削除
- 受注数・達成数・達成率などの統計
- 直近の承認ログ（誰がいつ何を承認したか）

### 階級・ランク設定 (`/dashboard/ranks`)

4段階の階級（新規住人 → 住人 → 常連住人 → 人気住人）ごとに、表示名・昇格に必要なマイル数・Discord自動付与ロール名を編集します。サーバー内に同名ロールが無い場合は、昇格時にBotが自動作成します。

### マイル手動操作 (`/dashboard/miles`)

管理者権限で特定ユーザーのマイルポイントを手動付与・没収します。理由を添えて操作すると、操作ログに記録されます。

### 総合操作パネル送信 (`/dashboard/panel`)

`/パネル設置` コマンドと同等の、採集・図鑑・マイル確認などがボタン1つで使える総合操作パネルを、任意のテキストチャンネルへ即座に送信します。

## 🗄️ データベースについて

このダッシュボードは以下のテーブルを読み書きします（Bot本体の `src/database/db.js` が作成・管理しているものと同一です）。

| テーブル | 用途 |
| :--- | :--- |
| `doumori_settings` | 基本設定画面の各種パラメータ |
| `doumori_missions_master` | ミッションマスター（作成・編集・削除） |
| `doumori_ranks_master` | 階級・ランクマスター |
| `doumori_mission_logs` | ミッション承認履歴（閲覧のみ） |
| `doumori_mile_logs` | マイル付与・没収履歴 |
| `doumori_miles` | ユーザーごとのマイル残高（手動操作時に更新） |

テーブルはBot本体の初回起動時に自動作成されるため、ダッシュボード単体で先に起動しても問題ありません（未作成の場合は空データとして表示されます）。

## 🔧 トラブルシューティング

- **ログインできない**: `DASHBOARD_USERNAME` / `DASHBOARD_PASSWORD` が `.env.local`（または本番環境変数）に正しく設定されているか確認してください。
- **チャンネル/ロールの選択肢が空になる**: `DISCORD_BOT_TOKEN` と `DASHBOARD_GUILD_ID` が正しいか、Botが対象サーバーに参加しているか確認してください。
- **保存してもBotに反映されない**: `DOUMORI_DATABASE_URL` がBot本体と同じデータベースを指しているか確認してください。
